0 核心命题：投资收益的三层来源
框架顶层公式
A股投资收益 = 基准(池子) + 数据端(因子) + 方法论 + 卖出时点

池子决定收益的高度（靠长远判断） · 因子决定超额的可量化性（一致预期已验证） ·
方法论决定 alpha 能否被稳定提取（当前只有刘旭式） · 卖出决定 alpha 的兑现率（估值类有效）

三条铁律： ① 每笔 alpha 只记一层（禁止重复记账）② 先对比等权万得全A 再下结论 ③ 无效实验也记账（防重复踩坑）

6 当前可用的投资决策方案

📋 决策1：当前选股推荐（刘旭框架）

回测验证 · 5.2年+7.1pp

运行入口：_lx_now_fetch.py → _lx_now_screen.py → _lx_now_score.py → _lx_now_dist52.py

  • 第一层筛选：市值≥100亿 + PE>0 + L4估值安全(PE≤25或股息率≥2%) + L5低预期(增速≤25%且0
  • 排序信念：PE升序（便宜优先）→ top-40 等权组合
  • 质量过滤：可选 LX-gm 层（毛利率≥中位 → 回撤砍半 -13.9%）
  • 六维度评分：价值50%(PE30%+PEG20%) + 质量25%(ROE15%+毛利10%) + 安全25%(股息15%+OCF10%)
  • 52周检查：近高点(≥0.95)=反应不足偏多 · 过远(<0.70)=规避

📊 决策2：C-Score 一致预期策略

回测验证 · +26.2pp

用分析师一致预期替代滞后财报的前瞻性选股，C1预期ROE>12% / C2预期增速>0 / C3 4周修正>0 / C4 13周修正>0，配合 BM(1/PB) 三分位矩阵。

  • 运行入口：examples/backtest_c_score.py / _cs_now_*.py
  • 优势：前瞻性替代滞后财报 · 10期8期跑赢等权全A
  • 输出：当前推荐名单（可剔除金融股）

🎯 决策3：行业内筹码集中度筛选（个股层）

IC验证 · 行业内Q1端+6.8%单调

申万筹码合成因子：个股层集中=机构锁仓(好)，Q1端（最集中）单调跑赢Q5端+6.8%/月。

⚠️ 铁律：筹码集中度只做行业内个股筛选/负面清单，禁止跨行业配置。 行业层集中=拥挤度过热(坏)，Q1−Q5平均 -3.97pp/月（4/6期集中端跑输）。

📈 决策4：52周高点距离检查（锚定效应）

裸测验证 · 待升格

Li&Yu 2012 反应不足机制：近52周高点 → 市场反应不足 → 偏多信号。

  • 近高点 (≥0.95)：反应不足，偏多信号 — 唯一裸测跑赢等权全A的行为信号(+12.3pp)
  • 较近 (≥0.85)：次优
  • 中等 (≥0.70)：中性
  • 过远 (<0.70)：L3规避 — 距高点过远的股票不买入（深跌抄底 -36.9pp）

框架内置

已验证有效（VERIFIED）：一致预期 PIT(+18.1pp) · 万得全A PIT · 刘旭式(+7.1pp) · F-Score(+8.1pp) · C-Score(+26.2pp) · ZHF否决(+4.7pp) · 估值卖出(+11pp) · BSADF调仓(+0.9pp) · G5涨幅分解
