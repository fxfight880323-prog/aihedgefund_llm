## ② 铁律（违反任何一条 = 返工。AI 若发现冲突，直接说"违反铁律 X"并停下说明）

| # | 铁律 | 一句话理由 |
|---|---|---|
| 1 | **真实数据**：禁止编造/模拟/合成市场数据做分析；拿不到就明说 | 用户第一原则，假数据结论全废 |
| 2 | **池子 = 万得全A PIT 成分**，禁止手工精选股票池 | 高收益可能是池子 beta / 幸存者偏差 |
| 3 | **统计颗粒度 = 日频**：月频引擎(T+1月末撮合)系统性高估收益、低估 MDD；历史月频数字引用须标注"旧口径" | core +60% 虚高 → 日频 +17.9% |
| 4 | **复权**：策略与基准必须同为复权口径；OHLC 按 adj/close 比例折算 | 未复权缺分红，高分红组合被低估（core +17.9% → 复权 +55.55%） |
| 5 | **同口径基准**：基准构造必须与策略同调仓频率/持有方式 | 每日再平衡等权 +93.5% ≠ 半年调仓等权 +41.1%，不可直接对比 |
| 6 | **零未来函数**：PIT 成分 as_of、HF 因子滞后 1 交易日探测、非交易日 as_of 映射到最近交易日、调仓日 T+1 撮合 | 用户四项验证原则之一 |
| 7 | **IC ≠ alpha**：高 IC 因子必须做 Q5−Q1 分位回测；月频 IC 与半年频排序收益口径不可互推 | 筹码成本 IC 0.038 被极端值污染，多空实际 -1.6% |
| 8 | **先对比再下结论**：任何策略/筛选收益必须先与"等权池子"对比 | 高收益可能只是池子 beta |
| 9 | **MDD 标准口径** = (peak − trough)/peak，按日频全序列计算 | 月频采样丢失月内回撤 |
| 10 | **金融剔除只用于展示层**：银行/非银金融剔除不进回测排序管线，只用于"当前推荐名单"展示 | PE 升序天然聚集低估值银行股，剔除砍掉 core 收益 85% 来源 |

## ③ 任务类型模板（选一段替换"任务描述"，可组合）

### A. 回测任务
```
请对 [策略/变体] 在万得全A PIT 成分池上做【日频】回测：
- 区间 2021-05 ~ 最新，半年调仓（PIT_DATES 10 期），调仓日收盘下限价单(close×1.2 buffer)、次交易日撮合（vnpy 语义）
- bar 用【复权价】；基准 = 同口径半年调仓等权全A + 中证全指(000985.SH)
- 输出：总收益 / 年化 / MDD(日频) / 超额(两个基准) / 每期持仓清单 / nav 序列
- 先跑"等权池子"对照组，再下结论
```

### B. 筛选任务（当前推荐名单）
```
池子：万得全A PIT 成分 + mv≥100亿 + 金融剔除(123只名单) + PB band 分位>90% 剔除
排序：价值50% + 质量25% + 安全25% 百分位打分（或按任务指定）
因子注意：HF 因子面板滞后 1 个交易日探测（须用前一交易日）；非交易日 as_of 估值面板返回 count=0
```

### C. 因子评估任务
```
- 月频 Spearman IC + Q5−Q1 分位收益（多空验证），区间 2019-02~最新
- 个股层 vs 行业层区分：筹码合成【行业层】已证伪（Q1−Q5 平均 -3.97pp/月），只做行业内个股筛选/负面清单，禁止行业配置
- 检查极端值污染（单期 IC 被极端行情扭曲）
- MCP 坑：get_factor_ic 的 start/end 必须完整 YYYY-MM-DD
```

### D. 诊断任务
```
校验：数据对齐 / 未来函数 / 持仓数量(目标=实际) / MDD 口径 / 复权一致性 / 撮合时点
输出：结构化检查点表格，每项 pass/fail + 证据
```

## 附：历史教训速览（铁律的由来，供 AI 理解而非背诵）

- **月频高估收益**：月频引擎 T+1 月末撮合 → 每调仓周期多持旧仓 1 个月。core 月频 +60.0% → 日频 +17.9%（-42pp 虚高）。
- **未复权低估分红**：core 持仓 80% 金融高分红（工行 adj/close=2.55）。复权后 core +17.9% → +55.55%。
- **基准构造差异巨大**：每日再平衡等权全A +93.5% vs 半年调仓等权 +41.1% vs 月度再平衡 +52.9%。
- **三个口径修正后核心结论不变**：金融剔除仍负贡献（core +55.55% vs finex +29.45%，-26.1pp）；PB band 仍正贡献（finex_band +34.48%，+5.03pp）；LX-core 真实同口径超额 +14.4pp。
- **金融剔除证伪**：PE 升序天然聚集低估值银行股，收益 ~85% 来自金融（占比 45%→80%），剔除后转负。
- **筹码合成行业层证伪**：个股层集中=机构锁仓(好)；行业层集中=拥挤度过热(坏)。只做行业内筛选。
- **GBM 量价"alpha"证伪**：90%+ 是小市值暴露（小盘占比 2021 52%→2026 90%），mv≥100亿 后超额归零；且仓位不能择时小盘（corr≈0）。
- **LX-core 仍是当前最强基准**；L2 层仅刘旭式长期有效；C-Score 一致预期 +26.2pp 超额（数据端最强信号）。
- **工程坑**：Bash/PowerShell 沙箱 cwd 可能损坏 → 用 Agent 子进程执行脚本；git push 用 `"D:/Git/cmd/git.exe" -c credential.helper=manager`；文件尾部旧常量会静默覆盖头部定义。
