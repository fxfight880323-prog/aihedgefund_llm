## 0. 核心命题

```
A股投资收益 = 基准(池子) + 数据端(股票池 + 因子) + 方法论 + 卖出时点
```

- 数据端：选对池子（远期判断） + 用好因子（可量化超额）
- 方法论：目前仅刘旭式框架经回测验证长期有效，其余待验证后登记
- 卖出时点：卖得好比买得好重要——热度 / 估值 / 均值回归驱动的卖出信号

## 3. L3 卖出时点 — 卖得好比买得好重要

### 四个卖出信号 · 证据分级

| 信号 | 证据状态 | 回测依据 |
|------|---------|---------|
| 估值过高 | ✅ 实测有效 | F-Score 加估值卖出 **+11pp**（有效改进） |
| 成长/价值风格分歧过大 → 均值回归 | ⏳ 待验证 | 逻辑成立（风格极端分化后回归）；无直接回测，可构造成长/价值价差信号 |
| 舆论一致性 / 热度过强 | ⏳ 待验证 | 无直接回测；热度数据可构造（同花顺热度 / westock / 一致预期分歧度） |
| 二阶导增速放缓 | ❌ 回测反例 | yoy_drop 下修清仓 MDD **-66.3%**；减速清仓无效；IRR 门控无效 → 增长类机械信号目前无证据 |
| 锚定-52周高点距离（买入侧） | ✅ 近高点有效 / ❌ 深跌抄底无效 | 近52周高点裸测 **+12.3pp** / MDD -16.6%（Li&Yu 2012 反应不足）；深跌抄底 **-36.9pp**（8期最差=接飞刀）→ 反向用作**规避**：距高点过远的股票不买入 |

### 关键教训（为什么卖出信号难）

- **卖出纪律 = 收益换回撤，非免费午餐**：机械清仓在持续下修期会"清仓接刀→割肉换血"循环（MDD -66%）
- **信号质量决定一切**：估值类信号（均值回归逻辑）有效；增长类机械信号（增速下修）无效
- 熊市半仓切换（-5.3%）等机械避险也无效——避险需要信号触发，不是定时切换

- [ ] 舆论热度信号：热度/一致预期分歧度 → 卖出的回测

|------|------|------|
| Growth Loop 纯增速 | -14.0% / MDD -56.6% | 买入点=YoY峰值 → 追高接盘循环（Growth Trap） |

| 减速清仓 | 无效 | 增长类卖出信号无证据 |
| yoy_drop 下修清仓 | MDD -66.3% | 超灵敏砍太狠 → 清仓接刀循环 |

| 熊市半仓切换 | -5.3% | 机械避险无信号触发 |
| F×C 乘数混合 | 无效 | 乘数混合不如各自独立使用 |
| 深跌抄底（距52周高点远） | **-36.9pp**（8期最差） | 半年度频率下跌深反弹不成立 → 接飞刀；与追高接盘对称，两个极端价格行为都不能反向交易 |
| 12月动量 / 12月反转排序 | -18.8pp / -20.8pp | 纯价格外推（外推信念）与反外推在半年调仓下均无 alpha |
| 刘旭池内替换排序（52wk/低波/反转/预期修正） | 全部跑输 PE 排序 | 行为信号与"便宜优先"信息重叠，替换排序稀释 alpha；排序信念仍是 PE 升序 |
| GBM 量价（全A PIT 池） | 超额 -0.4pp 打平；强制市值≥100亿后 **-40.6pp** | IC 0.114 全库第一但 alpha 90%+ 是小市值暴露（小盘占比 52%→90%）；换手 ~100%；不做核心层/增强层 |
| GBM 小盘仓位择时小盘 | corr = +0.08 ≈ 0（n=10） | 仓位最小值恰逢小盘行情起点——模型追涨，滞后非领先 |

## 5.5 2026-08-26 裁决记录（garp 采纳与案例）

- **L5 门控升级（已采纳）**：旧「增速≤25% + PEG≤2」→ 新「增速≤60% + 0&lt;PEG≤1」（garp）。8 变体回测最优：+34.57%（+5.12pp）/ MDD 18.54%（-3.6pp）；分年度验证超额来自 2022 熊市少亏 6.2pp（风控红利），2021 煤炭大牛年不押风格（-0.4pp）。机制 = 增速可高但估值必须匹配。**副作用**：格力/海尔/TCL智家等 PEG∈(1,2] 低增速白马被踢出池（名单从纯低估值白马转向低估值+成长匹配）。
- **紫金矿业（601899）案例**：不贵（PE 13.6 / ROE 32.9% / PEG 0.31），被旧 L5 增速门控误杀（增速 58%>25%）。garp 采纳后整批"紫金同类"回池（兰花科创/潞安环能/淮北矿业等煤炭航运有色高增长龙头）。当前 rank 47/182，评分口径入选最终名单。⚠️ 增速预期仍在 58% 且 4w 修正 +81% 上调中——突破 60% 将滑出 garp 池（高增长+高预期固有风险）。
- **福耀玻璃（600660）案例**：中 PE 中质量，q20/q50 混合排序均救不回（blend 46.7~53.8，排 100~128/226）；garp 采纳后因 PEG 1.3>1 被踢出池。裁决：不为单票开后门——排序/门控问题是框架诚实暴露。
- **质量放松 PE 排序边界**：q20（+3.40pp）只在边缘换 1-6 只低质股有效；two_bucket/qadj_pe 等大幅放松有害。福耀验证"混合排序救不了中段股"。

## 6. 一句话总结（2026-08-26）

**池子决定收益的高度（但靠长远判断），因子决定超额的可量化性（一致预期已验证），
方法论决定 alpha 能否被稳定提取（刘旭式 + garp 门控），卖出决定 alpha 的兑现率
（估值类有效、增长类机械信号无效）。**
