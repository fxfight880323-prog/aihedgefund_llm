# A股融资市场逻辑回测 —— 策略量化设计

## 一、用户原始逻辑（不可更改的原则）

**世界观**：A股是融资市场，核心目的是产业政策扶持、国家产业完善。
一轮完整周期：
```
产业扶持政策(发改委/工信部/证监会)
  → 国家队入场(汇金/证金)
    → 公募基金入场
      → 散户接盘
        → 产业成熟(公司开始盈利、盈利增速减缓)
          → 成长股变周期股，一轮扶持结束
```

**买入三条件**（不看盈利、不看估值）：
1. 产业扶持政策
2. 市场流动性支持政策
3. 国家队入金行动

**卖出条件**：
1. 企业开始盈利（盈利兑现 = 扶持目标达成）
2. 盈利增速减缓（成长性耗尽，成长股变周期股）
3. 国家队卖出 → **立即全部清仓**（最高优先级）

## 二、量化代理规则（声明所有默认假设）

### 信号 A：产业扶持政策（industry_policy）

- **规则**：行业获得"强扶持"事件 → 进入候选池，有效期 12 个月（逐月衰减）。
- **交叉验证**：用 neodata news 检索关键事件日期，用行业指数行情验证政策发布后行业超额收益。

### 信号 B：流动性支持政策（liquidity_window）
- **代理**：降准（RRR 下调）或降息（LPR/MLF/逆回购利率下调）事件后 **90 个自然日** = 流动性宽松窗口。
- **数据源**：tushare shibor_lpr（✅已验证 2016-2026 完整）+ akshare macro_china_rrr 交叉验证 + 央行公开事件表。
- **补充事件**（证监会层面）：2019 科创板开板、2023-08 印花税减半、2024-02 证监会换帅+暂停转融券、2024-09 一揽子政策（互换便利/回购增持再贷款）。
- **假设**：窗口期 90 天为默认参数；敏感性测试 60/120 天。

### 信号 C：国家队入金（national_team）
- **代理**：以下任一事件 = 入金信号：
  1. 汇金公告增持 ETF 或股票（2013、2015-07 救市、2015-08、2023-10-23 公告增持ETF、2024-02、2024-04 起持续增持宽基ETF）
  2. 汇金/证金在代表性个股十大流通股东中持仓上升（neodata shareholder ✅已验证）
  3. 2024-09 起互换便利(SFISF)/回购增持再贷款操作
- **信号有效期**：入金事件后 120 天。
- **清盘信号**：国家队明确减持（汇金减持公告 / 证金汇金持仓显著下降 / 2015-救市后逐步减持周期）→ **全组合清仓**。
- **交叉验证**：公告事件表 vs neodata shareholder 持仓变动。

### 卖出信号：行业盈利成熟（profit_maturity）
- **数据源**：neodata index_financials（申万行业季度财务 ✅已验证：ROE、归母净利润、增速）。
- **规则**（用户逻辑：开始盈利+增速减缓都是卖出条件）：
  1. **盈利兑现**：行业归母净利润 TTM 同比增速 > 阈值（默认 50%，即"开始大规模盈利"）→ 触发卖出观察
  2. **增速减缓**：增速二阶导转负（当季增速 < 上季增速，连续 2 季）→ 确认卖出
  3. ROE_TTM 从区间峰值回落 ≥ 2pct → 确认卖出
- **无未来数据**：以财报披露日（而非报告期）对齐，披露后 T+1 执行。

## 三、综合交易规则

```
买入：A(行业在扶持池) AND B(流动性窗口内) AND C(国家队入金120天内)
      → 等权买入该行业指数，最多持有 5 个行业
卖出：任一触发 →
      ① 行业盈利成熟(规则如上) → 卖出该行业
      ② 国家队减持信号 → 全部清仓（最高优先级）
      ③ 扶持池过期且无新事件 → 卖出该行业
执行：信号 T 日收盘确认 → T+1 收盘价成交（保守）
持仓成本：指数点位直算，双边费率 0（用指数回测的声明），另测 0.1% 单边敏感性
空仓状态：持有现金（不计利息，保守假设）
```

## 四、回测设定

- 期间：2016-01-01 ~ 2026-09-30（10年+）
- 标的：申万一级行业指数（akshare 申万官网源；声明：指数不可直接交易，实操需ETF，有跟踪误差）
- 基准：沪深300（tushare+neodata 双源交叉验证）、中证500
- 样本外验证：2016-2021 为规则校准期（政策事件表客观、无参数拟合），2022-2026 为样本外；同时做参数敏感性（窗口60/90/120、盈利阈值30/50/70%）
- 四项铁律：数据对齐（统一交易日历）、无未来数据（披露日/公告日对齐+T+1）、样本外验证、逻辑准确（每个买卖点可溯源到具体事件）
