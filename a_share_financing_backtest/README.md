# A股融资市场逻辑回测（Financing-Market Worldview Backtest）

基于"A股是融资市场"世界观的双Regime行业轮动策略回测，2016-01 ~ 2026-03。三轮迭代：V1单Regime → V2双Regime（杠杆消费）→ V3主题指数标的。

## 核心逻辑

**Regime 1 — 产业扶持（成长行业）**
- 买入三条件共振：①产业扶持政策 ②市场流动性支持政策 ③国家队入金行动（不看盈利、不看估值）
- 卖出：行业盈利成熟（盈利兑现后增速减缓 / ROE峰值回落）；国家队卖出→清盘

**Regime 2 — 消费吃药（居民杠杆驱动）**
- 买入：居民部门杠杆率年增量 ≥ 2pct（CNBS口径，披露对齐至次年3-31）→ 等权买入食品饮料/家电/医药
- 卖出：杠杆增量跌破2pct（平台期）→ 清仓消费池

## 回测结果（2016-2026）

| 版本 | 标的 | 总收益 | 夏普 | 最大回撤 |
|---|---|---|---|---|
| V1 严格（单Regime） | 申万一级行业 | +26.8% | 0.28 | -27.0% |
| V2 双Regime+大基金 | 申万一级行业 | +116.7% | 0.58 | -33.2% |
| **V3 双Regime+大基金** | **中证主题指数** | **+201.5%** | **0.64** | -39.7% |
| 沪深300基准 | — | +25.6% | — | -45.6% |

**V3标的更换实验（控制变量：信号完全相同）**：主题指数=同一产业逻辑的高beta表达——收益+85pct、夏普0.58→0.64，代价是回撤-33.2%→-39.7%。

标志性交易：中证白酒 2016-04 → 2022-04（杠杆平台期退出）持有2196天 **+402%**（同日买卖的申万食品饮料+243%）；半导体材料 2025-05→2026-03 +118%。

## 条件优先级消融（V2结论）

| 排序 | 条件 | 证据 |
|---|---|---|
| P0 冗余 | 流动性政策 | 去掉后 27.1% ≈ 基准 26.8% |
| P1 纪律性 | 产业政策/国家队 | 价值=锁定市场底部买点 |
| P2 放松 | 三选二投票 | +77.2% 但买点质量下降 |
| P3 最强增强 | 杠杆率双Regime | +92.7%~117.0% |

4. 逻辑可溯源：全部交易含理由字段
