# A股融资市场逻辑回测（Financing-Market Worldview Backtest）

基于"A股是融资市场"世界观的双Regime行业轮动策略回测，2016-01 ~ 2026-03。
**已完成独立审计（2026-10-02）：审计发现V3主题池3只指数身份标错并已修正（V3b），修正后结论以 +193.2% 为准，详见 `output/report_audit.html`。**

## 核心逻辑

**Regime 1 — 产业扶持（成长行业）**：产业政策+流动性+国家队三条件共振买入（不看盈利、不看估值）；卖出=盈利成熟（增速减缓/ROE峰值回落）或国家队卖出清盘。

**Regime 2 — 消费吃药（居民杠杆驱动）**：居民杠杆率年增量≥2pct → 买白酒/消费/医药；跌破阈值（平台期）→ 清仓。
