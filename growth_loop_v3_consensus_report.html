四、逐条归因（诚实评估）

改进对比效果结论归因分析
① 分析师一致预期买入过滤 v3a vs baseline -14.0% → +5.6% 正贡献（++0.2pp） 买入端叠加：必须有分析师覆盖 / 预期净利增速>0 / 近4周预期修正 rev4w>0（分析师在上调）/ PEG∈(0,2)。逐期滤掉 13-50% 候选（2023-04、2024-08、2025-04 约五成候选预期正在下调），留下的都是预期仍在改善的景气票。2025-04/2025-08 两期牛市 +35%/+44% vs baseline +20%/+35%；2024-08 期略逊（+44% vs +39%）但 2022-08 熊市 -18.0% vs -21.0% 更抗跌。
② 实际增速二阶导硬过滤 v3b vs v3a +5.6% → +5.1% 收益略降（-0.0pp），MDD 大幅收窄（+0.1pp） 实际营收 yoy 环比下滑即排除：2021-08 从 15→6 只、2022-08 从 27→14、2025-08 从 22→9。收益 -0.5pp 但最大回撤 -55.4% → -46.5%（+8.9pp）。代价是低仓期变多（2021-08 gross 48%、2024-08 48%），错过 2025-08 期部分弹性（+14.1% vs +44.4%）。适合风险偏好低的实盘；追求收益则用软加成版。
③ 完整配置（+纪律层） v3rec vs v3a +5.6% → +27.0% 强正贡献（++0.2pp） v3rec = v3a 买入端 + 二阶导软加成(加速票 conviction+0.1) + 风格开关（2022-08/2024-08 熊市 gross 50%）+ 估值卖出纪律（16 笔，PS/PS_med≥2 清仓）。与共识过滤存在强交互：共识池里的票估值纪律更有辨识度（全是高 PEG 弹性票），2022-08 减仓把 -18.0% 收窄到 -13.8%，2026-04 期 -3.4% vs v3a -16.5%（估值卖出+减仓共同避雷）。
④ 完整配置 vs 上一代 v3rec vs v2rec +0.7% → +27.0% ++0.3pp v2rec 只在卖出端/仓位端做文章，买入端仍会买进'增速亮眼但分析师正在下调预期'的票（财报增速滞后于预期拐点）。v3rec 把买入端换成'预期仍在改善'的池子后，卖出纪律和风格开关的杀伤力大幅放大：总收益 +0.7% → +27.0%，超额 -3.8% → +22.5%。

六、v3rec 机制拆解

① 买入端（分析师预期）：必须同时满足 有覆盖 / 预期净利增速>0 / 近4周预期修正 rev4w>0 / PEG∈(0,2)。淘汰「财务增速亮眼但预期恶化」的票。

② 增速二阶导（软加成）：实际营收 yoy 环比仍在上行（二阶导>0）的票 conviction +0.1，提高其权重排名；不硬排除，保留低仓期弹性。

③ 风格开关：2022-08、2024-08 两个调仓月基准 12 月收益 < -10% → gross 降至 50%。

④ 估值卖出纪律：持仓中任意月份 PS/PS_med ≥ 2.0 → 卖出（次月撮合）。共 16 笔。

八、局限与下一步

  • 回撤 -50.4% 仍偏高：虽然超额转正，但实盘 50% 回撤不可接受。下一步：PEG 上限网格（1.5/2.0/2.5）+ 分行业阈值；估值卖出可换用一致预期 PEG 触发（预期恶化即卖）而非只靠 PS 分位。
  • rev4w 阈值敏感性：目前 >0 即放行。可测试 rev13w/rev26w 更长窗口做「预期持续改善」确认，减少单周噪音。
  • 二阶导硬/软之争：v3b 回撤最优但收益略低。可做「熊市期启用硬过滤、牛市期软加成」的 state-dependent 组合。
  • 风格开关信号可升级：12 月收益 <-10% 是简单代理，可换 MA200/估值分位/分析师情绪宽度，减少 2024-08 的误判（当期少赚约 7pp）。
  • 预期数据时点：当前用调仓月末快照。若月度调仓，可用每月最新预期值，卖出端响应更快（预期下调当日即可减仓）。
