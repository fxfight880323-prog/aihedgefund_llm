6. 跨框架交叉：重叠与冲突

🔗 多框架重叠（交叉验证）
同一只股票被两个独立角度同时选中 = 证据增强
LX-core ∩ C-Score： 隧道股份
LX-core ∩ 筹码×52周： 无重叠——刘旭池(低估值价值)与AI科技池天然互斥，正是"不同角度"的体现
⚖️ 角度互补关系
三个角度覆盖三个互斥的收益来源
  • 刘旭式 = 买得便宜（价值回归）→ 偏周期/公用/基建/消费
  • C-Score = 买预期改善（分析师方向性上修）→ 偏金融/建筑/交运
  • 筹码×52周 = 买筹码锁定+趋势健康（供给端）→ 偏 AI 科技成长
  • dist52 = 不接飞刀（行为规避）→ 叠加在任何名单上
三者组合 ≈ 价值底仓 + 预期催化 + 科技成长 + 行为风控 的哑铃结构。
