1GOAL 层 — 参数设定

GOAL 层是策略的"宪法"——所有后续层的判定都以此为基准。参数来自 config/strategies/growth_loop.yaml：

剧本原话："Max single position 8% at cost" — 单票在任何时点占总资产不超过 8%。

2Universe 构建 — 全市场点时筛选

2024年8月调仓时，策略对全市场做点时（point-in-time）筛选：

  1. 增速排名：全市场按最新营收 YoY 增速降序排列
  2. 市值过滤：当前市值 > 50 亿（剔除微盘股）
  3. 无行业偏好：不排除任何行业（剧本原则："排除已知行业"的反面——先广撒网）
  4. 取 top-100：最终取增速最高的 100 只作为候选 universe

3HOOK 层 — 数值化筛选（核心）

HOOK 层是纯量化、可证伪的筛选门。剧本原则："A hook based on narrative alone (no numeric trigger) is invalid."——没有数值触发的 hook 是无效的。

3.2 计算 YoY 增速序列（同季对齐）

妙想报表是年内累计值（一季报=3个月/中报=6个月/三季报=9个月/年报=12个月），所以必须同季对上季比较：

YoY[0] = 2024Q2 / 2023Q2 - 1 = 650.37亿 / 110.14亿 - 1 = 489.7% YoY[1] = 2024Q1 / 2023Q1 - 1 = 265.96亿 / 51.01亿 - 1 = 421.7% YoY[2] = 2023Q4 / 2022Q4 - 1 = 358.42亿 / 340.43亿 - 1 = 5.3%

注意：YoY[2] 只有 5% 是因为赛力斯 2022 年还在卖传统燃油 SUV，营收基数已经不低；到 2023 年中开始与华为合作推出 AITO 问界系列，营收才爆发式增长。

3.3 计算毛利率序列（newest-first）

GM[0] = 25.04%（2024 Q2 中报） GM[1] = 21.48%（2024 Q1 一季报） GM 历史最低 (gm_floor) = 2.3%（2020-2021 年传统燃油车时期）

3.4 计算回撤（距 1 年高点）

取 2023-09 ~ 2024-08 月度收盘价窗口（13 个月） 窗口最高价 = 2024 年内高点 当前价 = 2024-08 月度收盘 drawdown = 1 - 当前价 / 最高价 = 16.8%

HOOK 层结论：触发 H1 + H2 两个钩子 → 获得进入下一层的资格（A 优先级候选）。

3.6 A/B/C 优先级排名

28 只候选中 22 只触发 ≥1 个 hook → 全部进入 A 优先级。排名规则：hook 数量多者优先，其次 YoY 增速高者优先。赛力斯以 2 个 hook + 490% YoY 排名靠前。

剧本原设计 A 上限 3 只是 LOOP 深研的 LLM 成本约束，不是组合规则——回测取全部触发 hook 的标的按信念加权。

4SERENITY 卡点审查门

SERENITY 门位于 HOOK 和 LOOP 之间，核心目的是区分结构性定价权（持续高毛利）与情景性利润（一次性暴利）。设计吸取了 2022 年新冠 IVD 教训（万孚/万泰/九安 GM 70%+ 拿最高分后均值回归崩塌 -26.4%）。

5LOOP 层 — L1-L7 LLM 门控深研（生产路径）

诚实声明：LOOP 层（L1-L7 LLM 深研）无法诚实回测——LLM 训练数据含未来信息。回测使用确定性代理（conviction_proxy）替代。以下是两层路径的说明。

5.1 回测路径（确定性代理）

回测跳过 L1-L7 和 SERENITY，直接从 HOOK 触发结果计算 conviction 代理：

conviction_proxy(n_hooks, hook_ids, latest_yoy): base = 0.5 + 0.2 × (n_hooks - 1) = 0.5 + 0.2 × (2-1) = 0.70 growth_boost = 0.3 × min(max(latest_yoy, 0), 1.5) / 1.5 = 0.3 × min(4.897, 1.5) / 1.5 = 0.3 × 1.0 = 0.30 h1_boost = 0.05 if "H1" in hook_ids = 0.05 conviction = min(1.0, 0.70 + 0.30 + 0.05) = 1.00 (capped)

growth_boost 被 1.5 封顶——YoY 490% 和 YoY 150% 在代理公式里是等价的，防止极端增速导致信念爆炸。

5.2 生产路径（L1-L7 完整深研）

在实盘运行中，SERENITY DOWNGRADE 的赛力斯会进入 L1-L7 七阶段 LLM 门控深研。每阶段 = 一次 LLM 调用，输出以机器可解析块结尾：

阶段主题PASS 条件确定性验证规则

5.3 L8 确定性信念计算

L8 是纯代码计算——LLM 不碰仓位。L1-L6 按权重加权（L7 是红队否决门，不贡献正向分数）：

STAGE_WEIGHTS = {L1: 0.15, L2: 0.20, L3: 0.20, L4: 0.15, L5: 0.10, L6: 0.20} # 权重总和 = 1.0 conviction = Σ(w_s × score_s) # 各阶段 LLM 评分 × 权重 # 黄旗减记：每面 YELLOW-FLAG -25% 信念，最多计 2 面 conviction *= (1.0 - 0.25 × min(yellow_flags, 2)) # 若 SERENITY 判 DOWNGRADE： conviction *= 0.70 # DOWNGRADE 折价

对于赛力斯，如果 L1-L7 全部 PASS 且无黄旗，L8 信念 = 加权平均分 × 0.7（DOWNGRADE 折价）。

6组合构建 — conviction_weighted + 8% 钳制

6.1 回测路径权重计算

7.2 L8 预承诺退出规则（入场后不可修改）

  1. Thesis kill：任何 L7 tripwire 触发 → 5 个交易日内退出 ≥50%，剩余部分重跑 loop
  2. Valuation kill：市场隐含 CAGR 超过 BULL 情景 → 减半
  3. Time stop：BASE-case KPI 连续 3 季度未达 → 无论价格退出
  4. Re-entry：仅在计算触发价处（市场隐含 CAGR = BASE）完整重跑 loop；不得穿越 tripwire 加仓

7.3 赛力斯的后续表现

赛力斯在 2024-08 入场后，恰逢问界 M9 爆发式增长和华为智选车模式验证，该期组合收益 +39.1%。但在后续 2025-04 调仓时，赛力斯不再出现在候选列表中——因为其增速开始从 490% 的基数回落，不再满足 H1 加速条件。
